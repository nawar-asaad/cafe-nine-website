# برنامج إدارة الصيدلية — صيدلية الرحمة (نسخة تجريبية)

برنامج كامل لإدارة الصيدلية حسابياً ومخزنياً يعمل من ملف واحد `index.html` داخل المتصفح، دون خادم ودون إنترنت (الخطوط فقط تُحمّل من الإنترنت إن توفر).

## التشغيل
افتح الملف `pharmacy/index.html` في Chrome أو Edge. تُحفظ البيانات تلقائياً في متصفح الجهاز نفسه.

## الأقسام
- **لوحة التحكم**: مبيعات اليوم والأسبوع والشهر، الأرباح، تنبيهات النواقص والصلاحية والمواد الراكدة، رسم بياني لآخر 14 يوماً.
- **نقطة البيع**: مسح الباركود بالقارئ أو البحث بالاسم، سلة بيع، خصم، حساب الباقي، إصدار وطباعة فاتورة (ورق حراري 80 مم).
- **المواد والمخزون**: الاسم التجاري والعلمي، القسم العلاجي، الرف، الكمية، الحد الأدنى، سعر الشراء والبيع، الصلاحية، الباركود. بحث وفلترة وترتيب حسب الرف أو القسم، واستلام كميات وجرد.
- **الأقسام العلاجية**: تصنيف المواد حسب التخصص العلاجي بألوان مميزة.
- **الرفوف**: كل رف برقم وقسم وموقع، مع عرض محتويات كل رف.
- **الباركود والملصقات**: توليد باركود فريد (13 رقماً يبدأ بـ 200) للمواد التي لا تملك باركوداً، وطباعة ملصقات بثلاثة مقاسات.
- **الفواتير**: البحث والتصفية حسب الفترة، عرض وطباعة، وإلغاء الفاتورة مع إرجاع الكميات.
- **التقارير**: يومي / أسبوعي / شهري / فترة مخصصة: المبيعات، أوقات الذروة، المبيعات حسب القسم، الكميات المصروفة، المواد غير المصروفة، وتقرير المخزون. تصدير CSV يفتح في Excel وطباعة.
- **الإعدادات**: تغيير اسم الصيدلية والعنوان والعملة، نسخ احتياطي واستيراد، ومسح البيانات التجريبية لبدء العمل الفعلي.

## اختصارات
`F1` لوحة التحكم · `F2` نقطة البيع · `F3` المواد · `F4` الفواتير · `F6` التقارير · `F9` إتمام البيع · `Esc` إغلاق النافذة.
